# แยกวันที่สำหรับแสดงผลกับวันที่สำหรับเครื่องจาก format และข้อยกเว้นเฉพาะจุด

ปลั๊กอินแปลงปีผ่าน filter วันที่ของ WordPress แต่มองไม่เห็นว่าใครเป็นผู้เรียก จึงตัดสินจาก format ที่ขอ: format ที่มีตัวปี (`y`/`Y`) ถือเป็นวันที่สำหรับแสดงผลและแปลงเป็นปี พ.ศ. ส่วนจุดที่รู้ว่าเป็นวันที่สำหรับเครื่องจะยกเว้นทีละจุด ได้แก่ ค่าคงที่ `DATE_*`, `'Ymdhi'` ที่บล็อก Post Date ของ WordPress 6.3–6.8 ใช้เทียบวันที่แก้ไขกับวันที่เผยแพร่, หน้า controls ของ Customizer ที่อ่านวันตั้งเวลาเผยแพร่ด้วย `'Y-m-d H:i:s'` และคำขอเวลาคอมเมนต์แบบ GMT หรือแบบไม่แปล (comment feed) เราไม่ยกเว้น `'Y-m-d H:i:s'` ทั้งเว็บ เพราะธีมใช้ format เดียวกันนี้แสดงผลด้วย และไม่ไล่ดู call stack เพราะเปราะและช้า

## Consequences

- โค้ดของธีมหรือปลั๊กอินอื่นที่ใช้ format ที่มีปีเป็นค่าสำหรับเครื่อง เช่น `get_year_link( get_the_time( 'Y' ) )` (issue #12) ยังได้ปี พ.ศ. ต้องยกเว้นเพิ่มทีละจุดเมื่อพบ
- ทุกครั้งที่ขยับ Tested up to ต้อง grep core หาจุดที่ส่ง format ที่มีปีเข้า `get_the_date()`, `get_the_time()`, `get_comment_date()` และ `get_comment_time()` เพื่อใช้เป็นค่าสำหรับเครื่อง
- เวลาคอมเมนต์สำหรับแสดงผลที่ไม่มีปีคงเป็น `H:i:s` แบบ 1.0.4 ตามนโยบายแก้ให้น้อยที่สุดของ 1.0.5 การแสดงตาม Time Format ของเว็บยกไปรุ่นถัดไป
